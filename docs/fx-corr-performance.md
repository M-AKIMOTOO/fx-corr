# FX 相関・phased RAW の高速化

`yi-corr` と `yi-phasedarray` は `src/main.rs` の計算処理を共有する。
2026-09-30 の変更では以下の無駄を削減した。

- RAW 作成のデコード・FFT・逆 FFT・合成バッファを計算ワーカーごとに確保し、全入力チャンクで再利用。
- RAW の周波数グリッド変換、アンテナの位相補正、ビーム合成を同じ走査で実行。グリッド変換の中間スペクトルとアンテナ別の整列済みスペクトルを廃止。
- RAW の診断を無効にした場合、phased power・ACF・XCF の計算と配列確保を省略。
- 量子化結果を出力チャンクへ直接書き込み、中間エンコード配列とコピーを廃止。量子化レベルを f32 で事前保持し、出力のビット置換を 4 個のバイト表で実行。
- 通常相関のデコード・FFT・累積用配列も全入力チャンクで再利用。並列還元の空の作業領域の確保を廃止し、計算ジョブ数をワーカー数に制限。
- gain 校正などの内部 XCF 専用処理でも、ACF 計算を除いた 8 レーンの相関カーネルを使用。
- 最終プロット用 ACF の累積はプロット生成時に限る。

FFT は f32、積分と位相発振器は f64 を維持する。RAW の位相補正の演算順、量子化の最小誤差判定と同値時のコード選択、DC/Nyquist 処理、LSB 復元、パック順を保持する。並列積分の加算順は変わるため、一般の入力について浮動小数点の完全一致を保証するものではない。

## 測定

Intel Core i7-12700H、既存の `target-cpu=native` と release 設定を使用。
2 bit の合成入力、33,554,432 sample/局、同じ配置の 2 局、1 秒、8 積分。
両版の入力は OS キャッシュに乗った条件。各版のウォームアップ後、実行順を交互に変えた 3 回の中央値。時間は起動と I/O を含む実時間。
`--cpu 4` は I/O 用 1 CPU と計算用 3 ワーカー。測定では `--no-affinity` を指定した。

| FFT | 総 CPU 数 | 相関: 変更前 → 変更後 (s) | 相関の倍率 | RAW: 変更前 → 変更後 (s) | RAW の倍率 |
|---:|---:|---:|---:|---:|---:|
| 128 | 1 | 0.1004 → 0.0943 | 1.07 | 0.4755 → 0.1988 | 2.39 |
| 128 | 4 | 0.0541 → 0.0546 | 0.99 | 0.2190 → 0.0991 | 2.21 |
| 4096 | 1 | 0.1053 → 0.0923 | 1.14 | 0.3945 → 0.2034 | 1.94 |
| 4096 | 4 | 0.0572 → 0.0552 | 1.04 | 0.1852 → 0.1054 | 1.76 |
| 65536 | 1 | 0.1874 → 0.1535 | 1.22 | 0.9198 → 0.2419 | 3.80 |
| 65536 | 4 | 0.1297 → 0.0826 | 1.57 | 0.4145 → 0.1282 | 3.23 |

全 12 条件で `.raw` / `.cor` の SHA-256 が一致した。
小 FFT の並列相関はほぼ同速であり、速度改善は FFT 長、計算ワーカー数、ストレージ、実際の遅延モデルに依存する。

変更前の release バイナリ 2 個を任意のフォルダへ保存してから、以下で再現できる。

```bash
cargo build --offline --release --bin yi-corr --bin yi-phasedarray
python3 benches/throughput.py --before /path/to/before --after target/release
```

## 検証

```bash
cargo test --offline --bins --test phased_raw_e2e
FX_CORR_BASELINE_DIR=/path/to/before cargo test --offline --test phased_raw_e2e reused_workers_preserve_rotated_mixed_bit_products
```

量子化テストは 1/2/3/4/8 bit、複数のビット置換、ワード端、量子化境界と同値、非有限値、非単調レベルを元のスカラー処理と比較する。
相関カーネルは独立した三角関数の参照値と照合し、ACF/XCF と XCF 専用の結果も比較する。
追加 E2E は 2/2、2/4、4/2 bit の組、USB/LSB、両出力グリッド、周波数回転、13.25 sample の遅延、1/3 計算ワーカー、5 フレームの短いチャンクで RAW と相関出力を比較する。`FX_CORR_BASELINE_DIR` を指定すると変更前のバイナリとも比較する。
