# 大気補正の検証

- `rtklib-niell.csv`, `rtklib-niell.json`: RTKLIB 原著者 C の `nmf()` で作成した72条件と、参照コードのハッシュ。Rust の単体試験と絶対差5×10⁻¹²未満で一致。

第三者の実観測データによる検証記録はローカル専用とし、Git の追跡・push 対象には含めない。

`tests/phased_raw_e2e.rs` の分散電圧試験は、40 MHzから始まる帯域に7本の線を入れ、局2に一次プラズマの位相を独立に注入する。正負1 TECU、LSB/USB、1.024 MHz の局別帯域差、20 TECU/s の時系列を試す。最後の値は計算経路の試験用で、観測値ではない。

補正を切ると各線に位相誤差が現れ、入れると元の各ビンで残留位相が0.015 rad（約0.86°）未満になることを確認する。通常相関・debug・1-binパルサー折り畳み・位相合成の残留位相も比較する。量子化・有限長の端点ゼロ埋めがあるためゼロとの完全一致は要求しない。振幅を合わせるためのフィットやビン移動はしない。

別の E2E 試験では、仰角が十分高い同一座標の基線を使い、VTEC＋気象入力を XML 定数・CSV 定数・UTC時系列・CLI置換で指定した結果が一致すること、明示 `off` が入力なしと一致すること、時間範囲不足で停止し ZIP `.info` が完結することを確認する。

実観測での改善量の評価には、低周波の観測データと対応する TEC・気象値が必要である。
