# 検証レファレンス

電離層・対流圏・地球中性大気の出版論文と取得状況は [atmosphere/](atmosphere/README.md) に保存する。公開用の数値検証には、標準モデルの参照値と合成データを使う。

第三者の観測データと、それに由来する設定 XML、解析配列、数値レポート、図、ログ、実行条件、ハッシュ一覧はローカル専用とし、ルートの `.gitignore` で Git の追跡対象から除外する。実観測ログを使った ZIP 互換性資料も同様に扱う。

観測 `.raw` は元データの場所で保持し、追加コピーは作らない。ローカル検証資料・再実行手順もローカル専用の保存先で保持し、push 対象には含めない。
